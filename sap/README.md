# SAP — Довідник транзакцій

## Стандартні / поширені

`COOIS`, `COGI`, `MM60`, `CS01`, `CS02`, `CS11`, `CS13`, `CS14`, `CS15`, `MB11`, `MB51`, `MB53`.

## Локальні Z-транзакції

`ZWNP`, `ZEBWM`, `ZMB52`, `ZMB5T`, `ZWMATA`, `ZWCSL`.

Для локальних транзакцій опис повинен ґрунтуватися на фактичній поведінці конкретної системи, а не на припущенні за назвою.
