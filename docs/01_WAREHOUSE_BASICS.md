# 01 — Основи складу

## Логіка складу

**приймання → ідентифікація → розміщення → зберігання → відбір → видача → повернення/коригування → інвентаризація.**

## Що контролювати

- матеріал;
- кількість;
- одиницю виміру;
- місце зберігання;
- партію;
- статус;
- документ-підставу;
- дату операції;
- результат у SAP.

## FIFO

FIFO (First In, First Out) означає використання раніше прийнятого матеріалу раніше, якщо локальні або технологічні правила не вимагають іншого.
