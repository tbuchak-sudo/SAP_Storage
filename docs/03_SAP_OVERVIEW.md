# 03 — Загальна логіка SAP

Для складу важливо розуміти зв'язок:

**матеріал → склад → залишок → документ → рух → результат.**

Стандартні SAP-транзакції мають загальне призначення. `Z*`-транзакції є локальними розробками, тому їх точну поведінку не можна визначати лише за назвою.

У документації окремо позначай стандартну логіку, локальну логіку та підтверджені особливості конкретної системи.
