# 04 — Виробниче замовлення

Виробниче замовлення пов'язує виробничу потребу з матеріалами та операціями.

Для складу потрібно розуміти:

- яке замовлення обслуговується;
- які матеріали потрібні;
- яка кількість;
- статус;
- коли матеріал потрібен;
- який документ підтверджує рух.

Базова логіка:

**замовлення → потреба → підбір → видача → підтвердження → контроль.**
