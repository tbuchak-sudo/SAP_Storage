# 08 — Інвентаризація

Послідовність:

1. Визначити область перевірки.
2. Підготувати матеріали та місця.
3. Провести фактичний підрахунок.
4. Зафіксувати результат.
5. Порівняти із SAP.
6. Виявити розбіжності.
7. Встановити причину.
8. Виконати коригування за затвердженою процедурою.

Розбіжність — сигнал для перевірки процесу, а не просто число для виправлення.
