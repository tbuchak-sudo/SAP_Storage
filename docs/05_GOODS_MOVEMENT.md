# 05 — Рух матеріалів

Перед рухом визнач:

1. Що рухаємо?
2. Скільки?
3. Звідки?
4. Куди?
5. Чому?
6. Який документ-підстава?
7. Який тип руху використовується у вашій системі?

Після операції перевір документ, залишок та фізичний стан матеріалу.

> Конкретні коди рухів не вигадуються: вони мають відповідати робочій SAP-конфігурації.
