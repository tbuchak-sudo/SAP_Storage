# 02 — Матеріали

Основні дані для роботи:

- номер матеріалу;
- опис;
- одиниця виміру;
- тип/категорія;
- склад;
- місце зберігання;
- залишок;
- статус;
- партія, якщо застосовується.

Не визначай матеріал лише за схожим описом. Основний ідентифікатор — код матеріалу.

Перед операцією звіряй **код + опис + одиницю + кількість**.
