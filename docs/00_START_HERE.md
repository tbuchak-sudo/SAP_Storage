# 00 — Початок навчання

## Головний принцип

Не просто запам'ятовуй кнопку або транзакцію. Розумій логіку:

**що робимо → навіщо → що перевіряємо → як виконуємо → який результат очікуємо → що робити при помилці.**

## Перед операцією

Перевір:

- код матеріалу;
- опис;
- кількість;
- одиницю виміру;
- склад/місце;
- партію, якщо застосовується;
- статус;
- документ або замовлення-підставу.
