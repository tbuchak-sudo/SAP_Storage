# SAP_Storage

Навчальна система для роботи зі складом, матеріалами та SAP.

## Мета

Практичний навчальний курс для працівника складу: від базових принципів роботи з матеріалами до SAP-транзакцій, руху матеріалів, виробничих замовлень, інвентаризації та пошуку типових помилок.

## Структура

- `docs/` — основний навчальний курс.
- `sap/` — довідник SAP-транзакцій.
- `warehouse/` — фізична логіка роботи складу.
- `training/` — уроки, вправи, тести та сценарії.
- `reference/` — терміни та довідкова інформація.

## Принцип навчання

Кожна тема пояснюється: **що це → навіщо → коли → що перевірити → покроковий алгоритм → результат → типові помилки → практика → контрольні питання**.

> **Важливо:** `Z*`-транзакції специфічні для конкретної SAP-системи. Їхню фактичну поведінку потрібно підтверджувати у робочій системі та внутрішніх інструкціях.
